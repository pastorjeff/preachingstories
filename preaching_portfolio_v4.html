Connect Google Sheet

Link your portfolio to a Google Sheet so new entries appear automatically every time the page is opened. This only needs to be done once.

① Upload CSV to Google Sheets

Go to sheets.google.com → create a blank spreadsheet → File → Import → Upload → select preaching_entries.csv. Choose Replace spreadsheet and Detect automatically. You should see three columns: Theme | Type | Text

② Publish as CSV

In your Google Sheet: File → Share → Publish to web. Set dropdowns to Sheet1 and Comma-separated values (.csv). Click Publish, confirm, then copy the full link shown.

③ Paste link & connect
✏ Adding new entries (ongoing)

Open your Google Sheet and add a new row at the bottom:

Column A — Theme (must match exactly)
Column B — Type: Story, Quote, or Reflection
Column C — Full text of the entry

Save the sheet. Refresh the portfolio. Done.
